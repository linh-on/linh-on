## Projects
**[Pawse](https://github.com/linh-on/pawse)** — A phone lockbox startup combining hardware (ESP32 + servo motor) with a React Native app and a fine-tuned MobileBERT notification classifier. Built for schools and individuals to stay focused.

**[Ableware](https://github.com/EliyaKhajeiee/ableware-pi-final)** — Voice-controlled assistive lift system. A Raspberry Pi listens for a custom wake word and sends commands over WebSocket to a hub, which routes them to a PyBullet 3D simulation and real Arduino-driven linear actuators in real time. Includes a TypeScript/React dashboard with live state updates and manual fallback controls. Stack: Python, FastAPI, WebSockets, TypeScript, PyBullet, Arduino, Raspberry Pi, Vosk (speech recognition), ONNX (wake word model).

**[Drama Tracker](https://github.com/linh-on/drama-tracker)** — Full-stack web app for tracking and organizing dramas and movies, integrating the TMDB API for real-time metadata and a content-based filtering recommendation engine. Stack: Next.js, TypeScript, PostgreSQL (Neon), Tailwind CSS, TMDB API, deployed on Vercel.

**[AI Spider Droid](https://github.com/t0nnaam/zims_ai_project)** — 3D-printed spider robot trained with PPO (PyTorch) and LiDAR input, deployed on a Jetson Nano for autonomous walking.

**[Deep Diabetes Risk](https://github.com/juliethecao/deep-diabetes-risk)** — Collaborative ML project predicting diabetes risk using deep learning. Stack: Python, Jupyter Notebook.
